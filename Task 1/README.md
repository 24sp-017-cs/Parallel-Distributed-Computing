How to run:
- for the .ipynb file upload it on jupyter notebook
- for the .py file run either option in the terminal or cmd:
    - python calculator.py
    - python3 calculator.py

Functions:
- add(a, b) //adding two numbers
- subtract(a, b) //subtracting two numbers
- multiply(a, b) //multiplies two numbers
- divide(a, b) //divides two numbers
- caluclator() //the backend of calculator, where the user can enter which operation they want to do
